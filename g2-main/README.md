# Agendar Cortadora a Laser (UC L2)

O aluno seleciona um bloco de horário disponível, o sistema valida as permissões por semestre e confirma a reserva.  
É possível incluir um suplente e o sistema envia e-mail de confirmação + lembrete no dia do uso.

![Wireframe L2](L2_agendar_laser_2.png)

---

*Interação do usuário:*  
1. Escolhe o bloco de horário.  
2. (Opcional) Insere suplente (TIA/E-mail).  
3. Confirma a reserva → recebe comprovante e e-mail.
